## About

Oceantype is a fun little project I made to learn about web development.

You can type out a message and send it into the ocean and other people can read them. Old messages are periodically recycled every now and then.

## Stack

- [Next.js](https://nextjs.org)
- [Tailwind CSS](https://tailwindcss.com)
- [Supabase](https://supabase.com)
- [react-spring](https://www.react-spring.dev)
- [Jotai](https://jotai.org)
- [motion](https://motion.dev)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Environment Variables

Create a `.env.local` file in the root:

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
```
